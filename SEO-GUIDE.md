# GreenPath Community Foundation — SEO checklist

This guide records the SEO work in the website and the steps that require the organisation's verified public website address or real-world account access.

## On-page SEO implemented

- Each main page has its own descriptive browser title and meta description.
- Page-specific keyword themes are included in metadata and reflected naturally in page headings and content.
- Each main page has one meaningful H1 heading, followed by section headings.
- Open Graph title and description metadata support clearer social link previews.
- Existing image alternative text has been reviewed; below-the-fold images use lazy loading and asynchronous decoding.
- The home-page hero image is prioritised for loading.
- Main pages link to one another through the shared navigation and footer.
- Responsive layouts and mobile navigation are maintained by the shared stylesheet.
- `robots.txt` permits normal crawling.

## Deployment steps still required

1. Confirm the final public website URL and make sure every page is accessible over HTTPS.
2. Create `sitemap.xml` using the final absolute page URLs, then add its full URL to `robots.txt`. Do not publish a sitemap with a guessed domain.
3. Add the verified canonical URL and `og:url` to each page after the final domain is known.
4. Register the site with Google Search Console and Bing Webmaster Tools, verify ownership, submit the sitemap, and monitor indexing and mobile usability.
5. Check every image filename against the actual image files before renaming. Keep filenames short, descriptive, lowercase and hyphen-separated; do not change a filename without updating every reference.
6. Test page speed with PageSpeed Insights or Lighthouse. Compress large images, serve modern formats such as WebP/AVIF where practical, and keep third-party scripts to a minimum.

## Off-page SEO and local SEO actions

These activities require real organisation accounts and genuine partnerships; they cannot be completed by changing website code alone.

- Create or update official social media profiles (for example Facebook, Instagram and LinkedIn) and link them to the verified website. Share useful project updates and link to the relevant programme pages.
- Ask genuine partner schools, community organisations, municipalities, sponsors and event partners to link to the relevant GreenPath pages when they publish project or partnership updates.
- Avoid paid link schemes, automated backlink services and unrelated directory submissions.
- If GreenPath has a staffed, eligible public-facing location, create or claim its Google Business Profile and keep the organisation name, address, phone number, opening hours and website consistent with the real details shown on the Contact page. Do not create listings for unstaffed or ineligible addresses.
- Submit accurate organisation details to reputable South African non-profit and community directories where eligible. Keep contact information consistent and request corrections when it changes.
- Encourage genuine partners and participants to leave honest reviews only on platforms where reviews are appropriate and permitted.

## Important accuracy note

Do not invent office details, opening hours, social profiles, project dates, backlinks or an official domain. Confirm these with GreenPath before publishing local business listings, schema markup, a sitemap or canonical URLs.
